# SEO Launch Checklist

## Before launch
- [ ] Confirm one canonical domain and HTTPS.
- [ ] Set `SITE_URL` in deployment environment.
- [ ] Check trailing-slash behavior and redirects.
- [ ] Verify title, meta description and canonical on every indexable route.
- [ ] Verify `robots.txt` and generated sitemap index.
- [ ] Ensure no staging URLs are indexable.
- [ ] Confirm 404 routes return a real 404 status.
- [ ] Validate structured data against current schema and Google tools.
- [ ] Check mobile usability, keyboard access and Core Web Vitals.
- [ ] Add original screenshots/diagrams where they help users.
- [ ] Check every internal link and remove orphan pages.
- [ ] Review privacy, terms, contact and consent implementation.

## Search Console and analytics
- [ ] Verify the domain property in Google Search Console.
- [ ] Submit the sitemap index after deployment.
- [ ] Inspect the homepage and main tool URLs.
- [ ] Configure GA4 only after the privacy/consent approach is ready.
- [ ] Track tool start, camera start, upload, sample, copy and palette extraction without sending image contents.
- [ ] Review queries and landing pages every 28 days; compare equivalent date ranges.

## AdSense readiness
- [ ] Publish original, useful content with clear editorial purpose.
- [ ] Add accurate About, Contact, Privacy and Terms pages.
- [ ] Ensure navigation and tools work on mobile.
- [ ] Do not place ads over controls or mislead users into clicking.
- [ ] Implement consent handling for applicable regions before ad tags.
- [ ] Keep ads disabled until publisher ID, policy setup and consent requirements are complete.
