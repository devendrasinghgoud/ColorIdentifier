# SEO, AEO and GEO Strategy

## Positioning
Primary search intent: identify a visible color from a car, motorcycle, object, camera or photo. Supporting intent: convert and understand digital color formats.

## Keyword clusters (seed ideas; metrics not yet validated)

| Cluster | Seed keywords | Target page |
|---|---|---|
| General identification | color identifier, identify color from photo, identify color from camera | `/color-identifier/` |
| Automotive | car color identifier, identify car paint color from photo, car paint color finder | `/car-color-identifier/` |

Do not treat these seed terms as validated volume, difficulty or ranking forecasts. Validate in Google Search Console, Semrush/Ahrefs or another keyword dataset before prioritizing. Record country, device, intent, volume, difficulty, SERP features and competitor quality.

## Search intent mapping
- Tool intent: put a working tool near the top of the landing page.
- Informational intent: answer the question directly, then explain limitations and steps.
- Automotive repair intent: make OEM-code limitations prominent and link to trusted manufacturer/dealer verification routes when researched.
- Color reference intent: show the actual swatch, exact digital values and original useful explanation.

## On-page SEO checklist
- One descriptive title and one clear H1 per page.
- Unique meta description and self-referencing canonical.
- Helpful introduction before deep explanation.
- Working tool and clear instructions.
- Descriptive headings and useful examples.
- Relevant internal links, not repetitive keyword stuffing.
- Original images/diagrams where they add information, with descriptive alt text.
- Breadcrumbs and semantic HTML.
- Index only pages that satisfy a distinct user need.

## AEO (answer-oriented content)
- Give a concise, direct answer in the opening paragraph.
- Define technical terms plainly.
- Use ordered steps for tasks and concise comparison tables when useful.
- Include FAQs only when they answer real follow-up questions.
- Keep visible content consistent with structured data.
- Do not promise featured snippets or AI citations.

## GEO (generative engine optimization)
- Publish accurate, attributable, well-structured explanations.
- State product capabilities and limitations explicitly.
- Use consistent entity naming for ColorCode Identifier and color formats.
- Add author/editorial accountability and updated dates.
- Cite primary sources when making standards or manufacturer claims.
- Make pages easy to understand without requiring interaction with the tool.
- Do not create fake statistics, fake reviews or unsupported expertise claims.

## Structured data
Use WebSite and Organization sitewide, SoftwareApplication on genuinely functional tool pages, Article on blog posts and BreadcrumbList when breadcrumb UI is present. Validate against Google's current documentation. Do not add FAQPage expecting rich results; Google restricts FAQ rich results to limited authoritative government and health sites.

## Internal linking model
Homepage → main scanner → car/bike landing pages → OEM paint code explainer → relevant articles.
Homepage → all tools → conversion/reference tools.
Blog articles link to one or two relevant tools and related articles where useful.
Color reference pages link to the color name finder, palette tool and image identifier.
Use descriptive natural anchor text. Avoid sitewide blocks of exact-match keyword links.

## Indexation controls
- Sitemap generated by Astro integration.
- robots.txt must use the real domain.
- Avoid indexing thin or duplicate query pages.
- Keep canonical URLs consistent with trailing slash strategy.
- Return proper 404 for unknown routes.
- Avoid creating thousands of color pages without meaningful unique content.

## Measurement
Track organic clicks/impressions, query/page CTR, indexed pages, tool starts, image uploads, camera starts, successful samples, copy events, palette extraction, Core Web Vitals and engaged sessions. Avoid sending image data or sampled personal content to analytics.
