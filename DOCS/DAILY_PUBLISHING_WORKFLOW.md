# Editorial Publishing Workflow

1. Choose one topic from the keyword map or Search Console query report.
2. Validate country, search intent, demand, difficulty and current SERP quality.
3. Identify the unanswered user question; do not select a topic only because a keyword tool shows volume.
4. Build an outline with a direct answer, clear steps, limitations, examples and relevant sources.
5. Add original screenshots, diagrams or calculations where they improve the article.
6. Link naturally to the relevant tool and one or two supporting guides.
7. Fact-check technical statements, dates, standards and automotive claims.
8. Add a unique title, description, category, tags and keywords in the Markdown frontmatter.
9. Preview desktop and mobile; check headings, images, links and accessibility.
10. Publish only when useful and complete; request indexing for important new pages when appropriate.
11. Review Search Console performance after enough data accumulates; improve existing pages before producing near-duplicates.

A daily cadence is optional. Editorial quality and accuracy take priority over publishing frequency.
