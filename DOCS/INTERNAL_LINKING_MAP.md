## Learning cluster
- Every blog post links to the most relevant tool in context.
- Related links should be editorially relevant, not mechanically identical on every article.
- Blog index links to every published article.
- Tool pages link to helpful articles that answer real questions.

## Rules
Use descriptive natural anchor text, ensure links are crawlable HTML anchors, avoid orphan pages, and review links when a page is renamed. Do not force every page to link to every other page.
